# Additional Options Redesign Design

**Section:** `#see-the-package`

**Goal:** Rebuild the "Additional options for excellent results" section so it follows the attached reference logic: centered intro, decorative light background, four icon-led cards in a 2x2 grid, no footer benefit strip, and no "Learn more" links.

**Approved direction:**
- Keep the section inside the existing landing page structure and brand palette.
- Use a centered intro block with an eyebrow, large heading, short supporting copy, and a small accent divider.
- Replace the current simple text cards with four white cards that each contain:
  - a soft green icon tile
  - a title
  - a short paragraph
- Use a reference-like background scene:
  - subtle green wave/radiating lines near the top
  - soft light glow behind the intro/cards
  - restrained dotted texture near the card field
- Reuse the project’s existing green SVG icon style where possible.

**Content mapping:**
- Foam Concrete Insulation Upgrade
- Price Lock / Quote Lock
- 3D BIM Model
- White-Label Kit for Builders

**Constraints:**
- Preserve the landing page’s responsive behavior.
- Keep typography aligned with the current site rules:
  - `h2` in `Michroma`
  - card body content in `Montserrat`
- Do not add CTA buttons or a lower feature strip.
